Connect coding agents such as **Bob (IBM)** and **Claude Code** to a PrimeAgent instance so they can build and run flows over MCP.

This page describes the <Icon name="Terminal" aria-hidden="true"/> **PrimeAgent MCP Client** entry in **Settings**. It is different from PrimeAgent's other MCP options.

- [**Use PrimeAgent as an MCP client**](./mcp-client): Use the **MCP Tools** component in flows so agent components _on the canvas_ can call external MCP servers or PrimeAgent MCP URLs.
- [**Use PrimeAgent as an MCP server**](./mcp-server): Use the **MCP Servers** page in PrimeAgent to expose your PrimeAgent project as an MCP server to desktop clients such as Cursor or Windsurf.

## Connect Bob (IBM) or Claude Code

To connect PrimeAgent to a coding agent, do the following:

1. Click your profile icon, select **Settings**, and then click <Icon name="Terminal" aria-hidden="true"/> **PrimeAgent MCP Client**.
2. Select the coding agent you want to connect to PrimeAgent, and follow the steps shown in the UI.

   All client configurations run `wfx-mcp` with `uvx`, and set `PRIMEAGENT_SERVER_URL` to your PrimeAgent server URL and `PRIMEAGENT_API_KEY` to a PrimeAgent API key of your choice.

   - To connect to **Bob (IBM)**, paste the configuration JSON into `~/.bob/settings/mcp_settings.json`, or use **Edit Project MCP** for a project-only setup.
   - To connect to **Claude Code**, run the `claude mcp add` command shown on the page, or manually add the JSON configuration to `~/.claude.json`.

   If you do not set `PRIMEAGENT_API_KEY`, the coding agent can log in with the PrimeAgent username and password you use to sign in to the PrimeAgent web UI for that server.

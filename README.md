## 🌍 **What Is PrimeAgent?**

**PrimeAgent** is an open-source, next-generation platform for building, deploying, and orchestrating **AI agents and workflows** — powered by code, or visually through an elegant interface.

> 💡 *PrimeAgent bridges the gap between no-code prototyping and enterprise-grade AI engineering.*

## 🔬 **REA Reverse Engineering for WFX**

The optional [`wfx-rea` extension](src/bundles/rea/README.md) adds authorized,
evidence-preserving REA MCP/CLI nodes to WFX workflows. Target paths are bounded
by operator-configured allowlisted roots; recovered target code is never run by
the integration.
